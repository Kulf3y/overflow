# Python Package

This folder contains the Python package for Overflow.

Package name:

```text
overflow-guard
```

Import name:

```text
overflow
```

## Local development

Create a virtual environment:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Install the package in editable mode:

```powershell
pip install -e python
```

Run the CLI:

```powershell
overflow --help
overflow check "Contact me at user@example.com"
```
