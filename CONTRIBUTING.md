# Contributing to Overflow

Thank you for your interest in contributing.

## Ground rules

- Be respectful.
- Keep changes small and focused.
- Write tests for new behavior.
- Do not add secrets or personal data.
- Do not make legal compliance guarantees.

## Development setup

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Run tests.
5. Open a pull request.

## Running tests

```powershell
powershell -File scripts\check_all.ps1
```

## Pull request process

- All changes require review.
- Automated checks must pass.
- Security-sensitive changes require extra review.
- Bots may open pull requests, but humans always merge.
