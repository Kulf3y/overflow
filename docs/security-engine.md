# Overflow Security Engine

The security engine provides early guardrail checks.

Current checks:

- Secret detection
- Basic prompt injection detection
- Fail-closed reporting

Important:

These checks are heuristic and not perfect.

They are designed to reduce risk, not guarantee perfect security.

Future improvements:

- Better secret classifiers
- Better prompt injection detection
- Output scanning
- Policy-driven enforcement
- Provider allowlist checks
- Audit integration
