# Overflow v0.1 Feature Guide

## Semantic caching

Overflow stores governed responses in a local SQLite vector cache.

If a new request is at least 85 percent similar to a cached request,
Overflow returns the cached answer without calling the AI provider.

This saves tokens, cost, and latency, and keeps data local.

Stats endpoint:

```text
GET /v1/cache/stats
```

## Streaming

The streaming endpoint returns Server-Sent Events:

```text
POST /v1/chat/stream
```

Overflow fully scans and governs the output first, then streams it
token by token. This is the secure buffered streaming mode.

## Transparency watermark

Every AI response is appended with an EU AI Act style notice:

```text
This content was generated by an AI system and routed through
Overflow governance middleware. Verify critical information before use.
```

## Rust bridge

Overflow can optionally use a compiled Rust engine for PII redaction.

Build it with:

```powershell
powershell -File scripts\build_rust_bridge.ps1
```

If the Rust module is not installed, Overflow automatically falls back
to the pure Python engine. Nothing breaks.
